Daftar Definisi

Berikut adalah contoh daftar definisi:

HTML
Hypertext Markup Language, bahasa standar untuk membuat halaman web.
CSS
Cascading Style Sheets, bahasa yang digunakan untuk mendesain tampilan halaman web.
JavaScript
Bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif.
PHP
Programming Language, bahasa pemrograman yang digunakan untuk membuat aplikasi web dinamis.
